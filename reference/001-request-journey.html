The six stops

StopWhat it doesReal file
1. Browser Types a URL / clicks a link → sends an HTTP request. app/static/js/ui.js and htmx.min.js enhance what the server sends
2. Router Matches the URL path against @router.get("/…") decorators, calls the matching function. This is the only place URLs are decided. app/students/routes.py:223 — @router.get("/students")
3. Gate Dependencies like Depends(require_login) run first; they check who you are (session) and what role you have, and reject the request with a redirect / 403 if you shouldn't be there. app/auth/deps.py — require_login, require_admin
4. Service Contains the actual business rules: what a student account is owed, what "overdue" means. Routers call services — never the database directly. app/students/service.py — StudentService.search_students()
5. Database SQLAlchemy models map rows to Python objects. Services query them in the current tenant scope. app/models.py — Student, Class, FeeTemplate…
6. Template Jinja2 HTML files mix markup with data via {{ value }} and {% for … %}. The router renders one with TemplateResponse. app/templates/students/search.html

Two render modes

  • Full page — a normal GET returns a complete HTML document.
  • HTMX partial — forms submit via HTMX (header HX-Request); the server returns just a fragment, and HTMX swaps it into the page without a reload.

Glossary

Request
A message your browser sends: GET (fetch a page) or POST (submit a form), with a URL.
Route / endpoint
A URL pattern a decorator maps to a function.
Router
The collection of routes for one feature (APIRouter).
Dependency / gate
A function FastAPI runs before the route handler, often checking auth.
Service
A Python class holding business rules; the router's workhorse.
Model
A class describing one database table (Student, FeeTemplate).
Template
An HTML file with Jinja2 placeholders that the server fills with data.
HTMX swap
Replacing part of the page with a fragment the server returned.
Session
The "who am I" cookie the server checks on each request.
Tenant scope
The current Campus every query is confined to (multi-school).
ORM
Object-relational mapper (SQLAlchemy): Python objects are the rows.
